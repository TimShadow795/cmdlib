01 Install

Copy one line into your executor. That's the whole install.

loader.lua
local Cmd = loadstring(game:HttpGet("https://raw.githubusercontent.com/TimShadow795/cmdlib/refs/heads/main/lib.lua"))()

The file ends with return T — that line is why loadstring hands you the Cmd table. Never strip it.

Alternate sources

02 Quickstart

quickstart.lua
local Cmd = loadstring(game:HttpGet("https://raw.githubusercontent.com/TimShadow795/cmdlib/refs/heads/main/lib.lua"))()

local term = Cmd.new({
    Title  = "Command Prompt",
    Prompt = "C:\\Users\\user>",
    Theme  = "default",
})

-- nuke all commands except help and version
term:ClearCommands()

-- register your own
term:Command({
    Name        = "hello",
    Description = "say hello",
    Usage       = "hello <name>",
    Callback    = function(self, args)
        self:Write("hello, "..(args[1] or "world"), Cmd.Colors.green)
    end,
})

term:Write("ready — type 'help'", Cmd.Colors.blue)
term:Notify({ Title = "Cmd", Content = "loaded" })

One instance at a time. Calling Cmd.new() again destroys the previous Cmd ScreenGui. This is intentional — no overlapping windows.

04 Methods

term:Write(text, color?)
Append a line to the scrollback. Auto-scrolls to bottom. RichText supported.
Write
term:Write("plain")
term:Write("ok", Cmd.Colors.green)
term:Write("<b>bold</b> RichText works", Cmd.Colors.cyan)
term:Clear()
Wipe every line from the scrollback. Same as typing cls. Does not clear flags or configs.
term:Notify({ Title, Content, Duration })
Top-right toast. Auto-fades after Duration seconds (default 4).
Notify
term:Notify({ Title = "Saved", Content = "config written", Duration = 3 })
term:Command({ Name, Description, Usage, Callback })
Register a command. See Callback contract for argument details.
term:ClearCommands()
Remove every command except help and version. Your entry point for a custom shell.
term:WipeCommands()
Remove literally everything, including help and version. Rarely needed.
term:AddBuiltins()
Restore the full default command set (colors, config, flags, set, cls, etc.).
term:SetTheme(name) → bool
Repaint the terminal to a named theme. Returns true on success. Chrome recolors live — no rebuild, no history loss.
term:Flag(name, default) → value
Declare a flag if not already set. Return its current value.
term:SetFlag(name, value)
Write a flag. Any type accepted.
term:GetFlag(name) → value
Read a flag. Returns nil if unset.
term:Config({ Name, Fields })
Register a config preset. Seeds flags only for keys not already defined.
term:Destroy()
Destroy the window. Same as exit / close / clicking the X.

06 Callback contract

Every command Callback receives three arguments:

signature
Callback = function(self, args, raw)
    -- self: the term instance
    -- args: lowercase table of arguments after the command name
    -- raw:  full typed line as typed
end

Typed farm 25 fast:

  • args[1] = "25"
  • args[2] = "fast"
  • raw = "farm 25 fast"
Errors are caught. If your callback throws, the dispatcher prints [!] <error> and continues. A crashed callback never kills the prompt.

09 Flags

Flags are the state layer. Loops read them, commands write them.

flags.lua
-- register defaults
term:Config({
    Name   = "default",
    Fields = { AutoRevive = true, TickRate = 100, BurstPerTick = 3 },
})

-- read from anywhere
if term:GetFlag("AutoRevive") then
    -- do the thing
end

-- write from anywhere
term:SetFlag("AutoRevive", not term:GetFlag("AutoRevive"))

-- loop that reads flags live
task.spawn(function()
    while term.Gui and term.Gui.Parent do
        task.wait(term:GetFlag("TickRate") / 1000)
        if term:GetFlag("AutoRevive") then
            -- your logic
        end
    end
end)

Type set AutoRevive false in the prompt — the loop picks it up on the next tick.

  • Keys starting with __d_ are internal config defaults — hidden from flags and config save.
  • set auto-casts true / false / numbers.
  • Config seeds only missing keys — never overwrites existing flags.

10 Configs

Saved under <executor>/Cmd/Configs/<name>.tcfg as JSON. Only flags not starting with __d_ are written.

prompt
C:\Users\user>config save pvp
saved: pvp

C:\Users\user>config list
configs:
  aggressive
  pvp
  stealth

C:\Users\user>config load stealth
loaded: stealth

C:\Users\user>config show stealth
{"AutoCollect":false,"AutoRevive":true,"BurstPerTick":1,"FarmCount":5}

C:\Users\user>config delete pvp
deleted: pvp
Filesystem fallback. If the executor lacks writefile / readfile, configs live in memory for the session only. Everything still works — just not across rejoins.

11 Starter script

Copy-paste. Runs out of the box.

starter.lua
local Cmd = loadstring(game:HttpGet("https://raw.githubusercontent.com/TimShadow795/cmdlib/refs/heads/main/lib.lua"))()

local term = Cmd.new({
    Title  = "Command Prompt",
    Prompt = "C:\\Users\\user>",
    Theme  = "default",
})

term:ClearCommands()

term:Command({
    Name        = "hello",
    Description = "say hello",
    Usage       = "hello <name>",
    Callback = function(self, args)
        self:Write("hello, "..(args[1] or "world"), Cmd.Colors.green)
    end,
})

term:Command({
    Name        = "add",
    Description = "add two numbers",
    Usage       = "add <a> <b>",
    Callback = function(self, args)
        local a, b = tonumber(args[1]), tonumber(args[2])
        if not a or not b then
            self:Write("usage: add <a> <b>", Cmd.Colors.yellow)
            return
        end
        self:Write(a.." + "..b.." = "..(a+b), Cmd.Colors.cyan)
    end,
})

term:Command({
    Name        = "toggle",
    Description = "toggle a flag",
    Callback = function(self)
        local v = not self:GetFlag("Enabled")
        self:SetFlag("Enabled", v)
        self:Write("Enabled = "..tostring(v), Cmd.Colors.green)
    end,
})

term:Command({
    Name        = "theme",
    Description = "switch theme",
    Usage       = "theme <name>",
    Callback = function(self, args)
        if not args[1] then
            self:Write("try: green lime matrix purple red blue cyan light solarized", Cmd.Colors.dim)
            return
        end
        if self:SetTheme(args[1]) then
            self:Write("theme -> "..args[1], Cmd.Colors.green)
        end
    end,
})

term:Config({
    Name   = "default",
    Fields = { Enabled = false, Speed = 10 },
})

term:Notify({ Title = "Cmd", Content = "ready", Duration = 4 })
term:Write("type 'help' for commands", Cmd.Colors.blue)

12 Input & controls

Typing

  • Click the prompt line to focus it
  • Type, press Enter to run
  • ↑ / ↓ cycles command history
  • Esc clears focus
  • Text persists across refocus

Parsing

  • Arguments split on whitespace
  • Lowercased before matching
  • Command keyword matched case-insensitively
  • Unknown command → '<line>' is not recognized.
  • Callback error → [!] <error>

Window controls

  • — minimize — collapse to titlebar height, click again to expand
  • □ maximize — grow 160×100, click again to reset
  • X close — hover turns red, click destroys
  • Drag the titlebar (excluding the rightmost 190px) to move the window

13 Gotchas

  1. One instance at a time. Cmd.new() destroys the previous window.
  2. return T is required at the end of lib.lua. Never strip it.
  3. Config path. <executor>/Cmd/Configs/<name>.tcfg. Session-only if no filesystem.
  4. listfiles sandbox. Some executors block it — config list then only shows this session's saves.
  5. Internal flags. Names starting with __d_ are config presets; filtered from flags.
  6. DisplayOrder 100. Draws above CoreGui. Raise the number in lib.lua if another UI renders on top.
  7. No game logic ships. The library is a shell — you register everything.
